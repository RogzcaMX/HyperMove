## 📖 Overview

**HyperMove** is an ultrafast, lightweight, and minimalist desktop application built to transfer large files and complete folders between computers on the same local network (LAN, Wi-Fi, or Ethernet cable)[cite: 14]. It maximizes your router or switch bandwidth with zero third-party intermediaries, external servers, or internet requirements[cite: 14].

---

## ✨ Key Features

* ⚡ **Direct Binary Streaming (TCP Raw):** Direct socket-to-socket channel between sender and receiver without unnecessary compression or file size limits[cite: 14].
* 📁 **Modular Drag & Drop (Folders & Files):** Full native drag-and-drop support, preserving complete folder hierarchies and internal directory trees.
* 🏛️ **Smart Routing & Windows Libraries:** Automatically sorts incoming items to your system *Downloads* directory or official Windows Libraries (*Pictures*, *Videos*, *Music*, *Documents*)[cite: 14].
* 🗂️ **Custom Subfolder Rules:** Automatic file classification by extension into clean target folders (`/Audio`, `/Compressed`, `/Documents`, `/Images`, etc.).
* 🛡️ **Duplicate Detection & Policies:** Real-time handling to skip, replace, or append numbered duplicates and custom folders[cite: 14].
* ⏱️ **Timed & Idle Auto-Shutdown:** Built-in server timers and inactivity triggers to safely close listeners after transfers finish[cite: 14].
* 📊 **Live Telemetry & Network Monitor:** Real-time transfer speed gauge (MB/s), overall progress bar, sent metrics, and batch transfer logs[cite: 14].
* 🎨 **Adaptive System Theming:** Native Light and Dark themes with automatic Windows mode detection and schedule support[cite: 14].
* 🌐 **Full Internationalization (i18n):** Complete English and Spanish support with automatic OS language matching or manual override[cite: 14].
